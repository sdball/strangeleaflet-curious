The Cabinet of Curios

Bitfield explorer

A set of bits is just a number until you decide what it means. Flip some bits, then read the same pattern as integers, text, a float, a color, a file mode, a date, or an address.

Keyboard: ~ invert, < > shift, [ ] rotate, + - add and subtract, 0 clear, r random.
