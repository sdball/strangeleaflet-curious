The Cabinet of Curios

Z-Machine Interpreter

Infocom wrote its games for a computer that didn't exist, the Z-machine, and shipped a small program for each real computer that pretended to be one. This page is one of those programs. It loads a story file and plays it: you type, the game answers.

Type a command and press Enter: look, take leaflet, go north or just n. ↑ and ↓ bring back what you typed before. save and restore keep games in this browser, and Undo takes back a move. Notes opens a notepad beside the game for clues and combinations, and Map draws the rooms you walk through as you go, with the things you've seen in each, and Redraw tidies it from every way you've found. In full screen, both are on the right end of the screen's top line. In the three Zorks, Enhanced adds a line under the status line with what the game keeps to itself: turns left on the lamp you're carrying, how much more you can carry, how long your wounds take to heal, and in Zork I, once you've opened the trophy case, the treasures in it. x works for examine in every game. Full screen gives the story the whole window, with nothing else on it, and Esc brings you back. Pick a screen to play on: a desk monitor, a green screen, an Atari 800, or a printout on fanfold paper. The page remembers where you were, so you can close it and come back.

Things to notice

  • The interpreter doesn't understand a word you type. It turns your line to lower case, splits it at spaces and at the few punctuation marks the game lists as separators, and looks each piece up in the game's dictionary. The game gets back a list: where each word sits in its dictionary, how long it is, and where it was in your line. Working out what put the crank in the socket means is the game's own code.
  • Only the start of a long word counts. A Version 3 game keeps six Z-characters of each dictionary word, and Version 4 and later keep nine. So in After Hours, examine odometry examines the odometer, since both pack to odomet.
  • In Version 3, the status line is the interpreter's job. The game only keeps the current room in its first global variable, and the score and moves in the next two. The interpreter draws the bar from those just before it reads a line, or when the game asks with show_status. From Version 4 on, games draw their own status line in an upper window.
  • The map knows where you are from the status line. In Version 3 it reads the same global the status line does. Later games draw their own status line, so the map takes the first object a game names there, which is the room in Inform and ZIL games. When the room changes after a command, the map draws that command as the way between the two rooms. When a direction leaves you where you were and the game describes the room again, as in Zork's maze, the map draws a small loop on that side of the room. A way you can't take says so without naming the room, so it draws nothing. A game that writes its room name some other way gets no map. Things go on the map once the game names them, or prints one of their own descriptions, while they're in your room, so whatever is still hidden stays off it.
  • Enhanced reads what the Zorks keep to themselves. The games know how long your lamp has left, how much more you can carry, and how long your wounds take to heal, and only hint at them: “The lamp appears a bit dimmer.”, “Your load is too heavy.”, or the numbers diagnose gives in Zork I. The line under the status line reads them from the game's memory each turn. Lights come from the clock, a table holding every timer: whether it's running, how many turns until it goes off, and which routine it calls then. The lamp's routine runs at each stage of a second table (in Zork I, 200 turns, then 100, 70, and 15), so the turns left are the turns to the next stage plus every stage after it, and turning the lamp off stops the clock. Load adds up the size of everything you carry, the way the game does before it lets you take something, and the limit drops while you're hurt. The page finds all this by the names ZILF lists when it builds each game, so Enhanced comes only with the built-in Zorks. Any command the game understands takes a turn, even walking into a wall, and wait takes three. Only a few, like save, score, and verbose, are free.
  • x means examine, even where the game never heard of it. The Zorks want examine lamp or look at lamp, and many players now type x lamp without thinking. When a game's dictionary has no x, the interpreter passes examine in its place at the start of each command. The game itself is unchanged.
  • A save is small. Everything a game can change sits in its dynamic memory, so a save needs only that, the stack, and where the game was in its code. This page stores only the bytes that differ from the story file as it was loaded, and says how many bytes each save took.
  • Restart doesn't reload the file. The game can't change static or high memory, so restarting copies the story file's dynamic memory back over the changed copy and starts at the first instruction again. Only the transcript and fixed-pitch bits of the header survive.

Where to find story files

People still write games for the Z-machine, and hundreds are free to download. The IF Archive keeps them.

  • The IF Archive's z-code folder lists them by file name, each with a line about the game.
  • IFDB, the Interactive Fiction Database, finds games by title, author, or subject. A game's page links to its download.

Files ending .z1 to .z5, .z7 and .z8 play here; .z3, .z5 and .z8 are the usual ones. A .zblorb wraps a story file with its cover art or sounds, and this page takes the story file out. Version 6 games (.z6) draw pictures and lay out their own windows, which this page doesn't do. Files ending .ulx or .gblorb are for Glulx, a different machine.

A few to start with, all on the IF Archive:

  • 9:05 by Adam Cadre, a few minutes long.
  • Photopia by Adam Cadre, first entered in the 1998 IF Competition.
  • Lost Pig by Admiral Jota, winner of the 2007 IF Competition.
  • Spider and Web by Andrew Plotkin, from 1998. Its file is called Tangle.z5.
  • The Dreamhold by Andrew Plotkin, written to teach newcomers how to play.
  • Curses by Graham Nelson, release 16 from 1995.

Most of Infocom's games are still under copyright, so this page doesn't link to copies. If you have the files from a copy you own, they play here like any other. Zork I, II, and III are the exception: their source is free under the MIT License, at historicalsource/zork1, zork2, and zork3.

The interpreter runs entirely in your browser. A story file you open never leaves your computer, and saved games, notes, and maps stay in this browser's storage.

After Hours at the Cabinet was written for the cabinet: after-hours.z3. Its source, and a station-by-station look inside it, are on The Z-Machine and how it runs stories. ZILF's library asks that games built with it name it in their opening credits, and After Hours does.

The three Zorks were built here with ZILF from the Infocom source Microsoft released, and each is shared under its MIT License: zork1.z3 (license), zork2.z3 (license), and zork3.z3 (license). Zork II needed one bracket moved before ZILF would compile it, and the Z-machine exhibit explains why that changes nothing in the game.
