The Cabinet of Curios

Minifloat ruler

An 8-bit float has only 256 bit patterns, so you can see every number it can hold. Flip the switches, then watch where the value lands on the ruler and how far it is to the next one.

Drag along the ruler and the value snaps to the nearest float. Negative numbers are a mirror image, so the ruler shows sizes only.

Round a number

Things to try

  • Start at zero and keep pressing Bits + 1. The first steps are all the same size. After that, the step doubles every time you pass a power of two.

  • Ask for 0.1. No minifloat equals it, and the report shows which neighbor it lands on and how far off it is.

  • Go to the largest number, then press Bits + 1. The exponent fills with ones and you reach infinity.

  • Keep the value at 1 and switch layouts. Every extra exponent bit doubles the range in powers of two and halves the steps between neighbors.

Every pattern

  • Zero
  • Subnormal
  • Normal
  • Infinity
  • Not a number

These layouts follow the IEEE 754 rules: an exponent of all zeros means zero or a subnormal, and all ones means infinity or NaN. The FP8 E4M3 format used in machine learning, which the bitfield explorer shows, drops infinity and uses those patterns for bigger numbers, up to 448. Not a Number shows how many different NaNs hide behind that all-ones exponent.

The layout and bit pattern live in the address bar, so you can share a link to any minifloat.
