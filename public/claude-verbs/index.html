The Cabinet of Curios

Claude Verbs

While Claude Code works, its spinner shows a rotating verb: Accomplishing, Architecting, Baking. Light up a few lines of themed verbs, listen to them play on hold, then copy one shell command that backs up your settings and writes the verbs in.

Press a line to pick its playlist. Open a playlist to leave out single verbs, or type your own. The command at the bottom needs jq, and nothing leaves your browser until you paste it into a terminal.

Station 1

Pick the lines

Each key is a playlist. Press one to light its lamp and put its verbs on hold. Press it again to hang up. Verbs play in the order you lit the lines.

Things to notice

    
    
      
  • No restart needed. Claude Code watches its settings files and reloads them when they change, so the next turn already plays the new verbs.
    • 
      
  • Mode and “verbs already there” are two different questions. Mode decides whether Claude Code mixes your list with its own verbs. The other choice decides what happens to verbs your file already lists before the new ones are added.
    • 
      
  • Nothing is lost. The command copies your settings to a .bak file stamped with the date and time before it changes anything, and prints the line that puts it back. It only writes when jq succeeds, so a file it can't read is left alone.
    • 
      
  • Every other setting stays put. jq rewrites the spinnerVerbs key and nothing else. If your settings file is a symlink into a dotfiles repo, the write goes through the link instead of replacing it.
    • 
      
  • Swapping only knows these playlists. “Swap out ours” removes any verb that appears on a line here, then adds your picks. Verbs you wrote yourself stay, and so do verbs from older versions of a playlist.
    • 
      
  • An empty list hands the spinner back. In “only mine” mode with no verbs, Claude Code keeps its own. The command goes one step further and removes the key, so the file looks as if you never touched it.
    • 
      
  • Short verbs play best. The verb shares a line with the timer, so a long one wraps or gets cut off in a narrow terminal. A gloss in parentheses, like the Infocom spells have, is fun but costs room.
